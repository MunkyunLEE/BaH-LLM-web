## 새 기능 자체 검증

- 미러 대칭: 미우라 6x4 전체 모델과 x 대칭 반 모델의 변위 상대오차 1.6e-15, 전체 에너지 74.4639 / 반 모델 ×2 74.4639
- 기하 접촉 (`tests/feature/contact.py`): 바닥 판 위로 45° 날개 판을 힘으로 접음. 접촉 끔 → 날개가 바닥을 뚫고 z = -11.5 mm. 접촉 켬 (간격 0.2 mm) → 최소 거리 0.356 mm 에서 멈추고 하중 계수 7.9 까지 버팀. 강제 변위로 바닥 안쪽까지 밀면 최소 거리 0.2 mm 에서 `contact_blocked` 로 멈춤. 접촉 쌍마다 경사·헤시안 수치 미분 오차 1e-10 이하 (평행 선-선 보정 포함)
- 압력 Local 하중 강성, 바·힌지 강성, 탄소성 힌지 접선: 수치 미분과 비교 1e-11 수준 (`core/tools/fdcheck.cpp`)
